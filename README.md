## 视频里能看到什么

| 时间 | 内容 |
|---|---|
| 0:00 – 1:20 | 真机在蓝垫子上按路线走到灭火器旁，到点停下 |
| 1:20 – 3:20 | RViz：地图、代价地图、车的位置与导航状态 |
| 3:20 – 4:40 | 录点：走到位置 → 填路线名 / 任务 / 期望值 → 存进路线库 |
| 4:40 – 5:00 | 中途取消，下次从上次的断点继续 |
| 5:00 – 6:19 | 控制台功能：一键启停、日志分级、AI 助手、报告与摘要 |
